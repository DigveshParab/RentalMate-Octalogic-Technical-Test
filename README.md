# 🚘 Vehicle Booking App

A minimal full-stack application to book vehicles by answering a series of questions. Built using:

- **Frontend:** React (TypeScript), Tailwind CSS, Material UI, Yup  
- **Backend:** Node.js, Express, Prisma, PostgreSQL (Neon DB)

---

## 📁 Project Structure

```
vehicle-booking-app/
├── backend/       → Backend API with Prisma + Express
├── frontend/      → Frontend React app using Tailwind + MUI
└── README.md      → Project overview and instructions
```
